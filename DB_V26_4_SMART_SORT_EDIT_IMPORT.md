# DB V26.4 — Smart Sort + Edit Modal + Import

## Что сделано

- Работает по реальной структуре `#ep-db-v26`.
- Убраны накладные V26.1/V26.2/V26.3 из подключения, оставлен один чистый V26 core.
- Автосортировка по примеру JSON:
  - `n` → название,
  - `p` → цена,
  - `u` → единица,
  - `c` → папка/категория,
  - `sc` / `g` → подпапка.
- Если старая миграция свалила всё в `Работы / Без подкатегории`, V26.4 раскладывает позиции по папкам из эталонного JSON.
- Карточка позиции открывается всплывающим окном и редактируется без `prompt`.
- Экспорт JSON отдаёт `workDB` и `matDB`.
- Импорт JSON/текста показывает предпросмотр, новые позиции и дубли.
- Для фото/PDF/Excel показывается предупреждение: нужен ИИ/OCR/парсер, файл не отправляется без отдельного подключения.

## Не трогали

- Главный экран.
- Визуал бургер-панели.
- Щит, пул, сметы и остальные функции.
