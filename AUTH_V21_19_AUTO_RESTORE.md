# Auth V21.19 — Auto Restore

После обновления страницы пользователь не должен снова нажимать «Вход».

Что добавлено:

- Firebase Auth persistence LOCAL;
- ожидание восстановления currentUser;
- автоскрытие экрана входа;
- автоматическое открытие приложения, если пользователь уже авторизован;
- диагностика auth-restored / auth-missing.

Важно: если браузер очистил данные сайта или пользователь нажал «Выйти», вход потребуется снова.
