# V29.20 Admin Workspace Core — структура админки

## Верхний блок

`Пользователи, подписка и ИИ-баланс`

Назначение:
- открыть пользователя;
- посмотреть его документы;
- подготовить тариф;
- подготовить срок подписки;
- подготовить ИИ-режим;
- подготовить баланс ИИ.

На текущем этапе сохранение идёт вручную через Firebase Console/старую админку. Прямая клиентская запись выключена.

## База данных

Каркас под будущую работу с БД мастера:
- выбрать пользователя;
- открыть его личную базу;
- добавить позиции в серверную базу;
- добавлять позиции с ценой или без цены.

Логику этого блока оставляем Claude.

## Логи ошибок

Только ошибки:
- `auth-error`;
- `firestore-denied`;
- `save-error`;
- `decrypt-error`;
- `crash`;
- `security-error`.

Не писать в логи обычные клики, переходы по меню, навигацию и шумную диагностику.

## Остальные блоки

- Бухгалтерия;
- Документы;
- Черновики;
- Сметы.

Все сделаны как раскрывающиеся разделы с понятными будущими путями Firestore.
