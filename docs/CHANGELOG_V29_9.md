# V29.9 Visual Control Core

Добавлен чистый модуль настроек визуализации из основного проекта:
- темы: Аврора, Графит, Изумруд, Закат, Океан, Фиолет, Карбон, Лёд, Роза, Моно;
- режимы: день, ночь, авто;
- быстрые профили: ночной, на объекте, дневной, эконом, премиум, читабельно;
- ручные цвета фона, карточек, текста, кнопок и акцента;
- прозрачность карточек и кнопок;
- скругления, blur, масштаб шрифта;
- плотность интерфейса, форма кнопок, стиль фона;
- анимации, звук и виброотклик.

Новых временных файлов не добавлено.
