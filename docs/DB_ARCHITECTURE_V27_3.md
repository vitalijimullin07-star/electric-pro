# DB Architecture V27.3

## Решение по активной базе

На переходном этапе редактор БД остаётся старым V26, а подбор работ/материалов уже новый V27.

Поэтому источник активной базы:

1. `epdb26_active_base` — приоритетный, потому что его меняет рабочий редактор БД.
2. `epdb27_active_base` — зеркало для новых модулей.
3. `epdb27_active_base_meta` — служебная запись с датой и источником.

Допустимые значения:

```text
my
server
```

`masters` не используется для подбора в смету и приводится к `my`.

## Почему так

В V27.2 `epdb27_active_base` мог остаться `my`, даже если в V26 редакторе пользователь выбрал `server`. Из-за этого picker открывал «БД моя» по умолчанию.

V27.3 исправляет это: старый V26 выбор зеркалится в V27, а V27 gateway читает V26-ключ первым.
