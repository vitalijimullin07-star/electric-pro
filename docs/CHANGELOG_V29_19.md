# V29.19 Admin Visual Core

## Что добавлено

- Сделан чистый визуал админки V29 без записи в защищённые поля.
- Добавлен красивый экран администрирования доступа.
- Добавлены карточки: профиль, подписка, ИИ, режим безопасности.
- Добавлены быстрые пути Firestore:
  - `users/{uid}`
  - `user_subscriptions/{uid}`
  - `ai_accounts/{uid}`
- Добавлен генератор шаблонов документов для Firebase Console.
- Добавлена проверка UID мастера в режиме чтения.
- Добавлены кнопки копирования UID, путей и шаблонов JSON.

## Что не трогалось

- Cloud Functions не деплоились.
- Firestore Rules не деплоились.
- Старый проект `electric-pro` не менялся.
- Защищённые блоки БД/щит/материалы/работа/однолинейка не трогались.

## Безопасная логика

V29.19 продолжает работать как клиент к существующему Firebase `electric-489f7` в режиме чтения. Управление подпиской и балансом на этом этапе выполняется через Firebase Console или старую рабочую админку.
