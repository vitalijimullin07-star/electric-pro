# CHECKLIST V29.20 Admin Workspace Core

После установки проверить:

1. Открыть `https://vitalijimullin07-star.github.io/electric-pro-refactor/?fresh=2920`.
2. Войти через Google.
3. Открыть админку.
4. Проверить, что сверху есть кнопка/раздел «Пользователи, подписка и ИИ-баланс».
5. Вставить UID пользователя и нажать «Открыть».
6. Проверить поля: роль, статус, тариф, срок, ИИ-режим, баланс.
7. Изменить тариф/баланс и проверить, что предпросмотр JSON меняется.
8. Нажать «Скопировать всё для Firebase».
9. Проверить разделы: База данных, Логи ошибок, Бухгалтерия, Документы, Черновики, Сметы.
10. Убедиться, что старый проект `electric-pro` работает.

Важно:
- Если список пользователей не загружается, это может быть нормальным: текущие Firestore Rules могут запрещать query коллекции `users`.
- В таком случае открывать пользователя вручную по UID.
- Кнопка записи из V29 пока специально не пишет в Firebase.
