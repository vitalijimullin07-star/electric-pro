# V29.19 Admin Visual Core — назначение

Этот этап делает админку визуально удобной, но не включает опасную запись в защищённые поля.

## Текущий режим

```txt
V29 refactor → Firebase Auth → Firestore electric-489f7 → чтение доступа
```

## Что можно делать через этот экран

- Смотреть текущий UID, email, роль, тариф и ИИ-статус.
- Копировать UID.
- Копировать пути документов в Firestore.
- Копировать шаблоны полей для Firebase Console.
- Пробовать читать карточку мастера по UID, если правила Firestore это разрешают.

## Что пока нельзя делать

- Сохранять тарифы из V29 напрямую.
- Менять ИИ-баланс из V29 напрямую.
- Назначать роль admin из V29 напрямую.

Эти действия позже должны идти через Cloud Functions, а не напрямую из клиента.
