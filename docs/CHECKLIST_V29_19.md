# CHECKLIST V29.19 Admin Visual Core

## Проверить после установки

1. Открыть `https://vitalijimullin07-star.github.io/electric-pro-refactor/?fresh=2919`.
2. Войти через Google.
3. Открыть админку из бургер-меню или страницу `pages/admin.html` через роутер приложения.
4. Проверить визуал:
   - hero-блок;
   - карточки статуса;
   - блок текущего пользователя;
   - блок путей Firestore;
   - шаблоны `users`, `user_subscriptions`, `ai_accounts`.
5. Нажать «Скопировать UID».
6. Нажать «Копировать» у путей Firestore.
7. Нажать «Скопировать шаблон».
8. Вставить свой UID в проверку UID и нажать «Проверить UID».
9. Убедиться, что старый проект `electric-pro` работает.

## Важно

- Если чтение чужих UID не работает, это нормально: текущие Firestore Rules могут запрещать прямое чтение чужих профилей.
- Никаких deploy rules/functions на этом этапе делать не нужно.
- Новая админка пока визуальная и read-only.
