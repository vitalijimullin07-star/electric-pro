# V29.20 Admin Workspace Core

## Что добавлено

- Админка перестроена в виде раскрывающихся блоков.
- Вверху добавлен основной блок «Пользователи, подписка и ИИ-баланс».
- Добавлен выбор пользователя по UID и попытка загрузки списка пользователей из `users`.
- В карточке пользователя добавлены поля:
  - роль;
  - статус;
  - тариф;
  - срок подписки;
  - ИИ-режим;
  - баланс ИИ;
  - комментарий администратора.
- Добавлен предпросмотр документов для Firebase Console:
  - `users/{uid}`;
  - `user_subscriptions/{uid}`;
  - `ai_accounts/{uid}`.
- Добавлены разделы-кнопки:
  - База данных;
  - Логи ошибок;
  - Бухгалтерия;
  - Документы;
  - Черновики;
  - Сметы.
- Логи описаны строго как error-only, чтобы не засорять приложение.

## Что оставлено безопасным

- Прямая запись защищённых полей из V29 отключена.
- Cloud Functions не деплоятся.
- Firestore Rules не деплоятся.
- Основной проект `electric-pro` не трогается.
- БД/щит/материалы/работа/ручная однолинейка не трогаются.

## Логика

На этом этапе V29 показывает правильный визуал будущей админки и готовит данные для внесения через Firebase Console или старую рабочую админку. Позже сохранение будет подключено через Cloud Functions.
