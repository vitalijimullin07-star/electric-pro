# Database V24.4.1 — UI + Server + Masters Fix

## Исправлено

1. Галочки добавлены на папки и подпапки.
   Теперь можно выделить папку/подпапку и удалить выбранное.

2. Папки по умолчанию свернуты.
   Добавлена кнопка `Развернуть / Свернуть`.

3. Исправлено выравнивание Работа / Материал.
   Скрыт прыгающий бейдж версии внутри вкладок.

4. Синхронизация сервера стала надежнее.
   Пробует несколько путей Firestore:
   - user_db/{uid}
   - ep_user_database_v24/{uid}
   - users/{uid}/private/database
   - server_db/main
   - global_db/database
   - ep_database_v24/server

5. Для админа добавлена попытка загрузки мастеров из:
   - user_db
   - ep_user_database_v24

## Важно

Если сервер всё равно пишет, что недоступен, значит проблема уже не в интерфейсе, а в Firestore Rules/путях коллекций. Тогда надо смотреть правила Firebase.
