# V21.4 Pool Compact Fix

Исправляет проблемы после V21.3:

- кнопки высот, постов и плюс/минус перехватываются отдельным фикс-слоем;
- плавающая шапка пула стала компактнее;
- добавлен 6-й пост в рамке;
- максимум 6 механизмов в одной рамке;
- если механизмов больше 6, плюс больше не добавляет;
- если постов меньше, чем механизмов, посты автоматически подтягиваются;
- после кнопки «Добавить в Пул» рамка сбрасывается к базовым значениям:
  - высота 30;
  - 1 пост;
  - 0 розеток;
  - 1 выключатель;
  - остальные 0;
  - количество рамок 1.

## Важно

Это временный фикс поверх V21.3.

После того как пул будет полностью проверен, нужно будет собрать его чисто без патчей.
