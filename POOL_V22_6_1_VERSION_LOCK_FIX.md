# Pool V22.6.1 — Version Lock Fix

После подключения V22.6 версия появлялась на секунду, затем V22.5.1 снова перетирал бейдж версии своими таймерами.

V22.6.1:
- запрещает V22.5.1 перетирать бейдж, если загружен V22.6;
- подключается после V22.6;
- повторно выставляет версию после старых таймеров;
- сохраняет ручной выбор кандидатов главным слоем.
