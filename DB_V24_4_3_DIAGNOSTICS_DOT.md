# DB V24.4.3 — Diagnostics Dot

Добавлена маленькая диагностическая точка на экране БД.

## Что делает

- Показывается только когда открыт экран БД.
- Зелёная: ошибок БД не поймано.
- Красная: пойманы ошибки БД или статус сервера содержит ошибку.
- По нажатию открывает панель «Диагностика БД».

## В панели

- Обновить;
- Копировать;
- Экспорт JSON;
- Очистить.

## Что попадает в диагностику

- версия точки;
- версия модуля БД;
- активная БД;
- раздел Работа/Материал;
- статус local/server;
- количество позиций в my/server/masters;
- нужные localStorage-ключи;
- пойманные ошибки JS/Promise по БД/Firebase/Firestore.
