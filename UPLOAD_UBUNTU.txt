Как загрузить на GitHub через Ubuntu

1. Распакуй архив.
2. Перейди в папку проекта:
   cd electric-pro-start-v1

3. Если репозиторий новый:
   git init
   git add .
   git commit -m "Start visual shell v1"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPOSITORY.git
   git push -u origin main

4. Если репозиторий уже есть:
   git add .
   git commit -m "Start visual shell v1"
   git push

Проверка:
- открыть index.html через GitHub Pages;
- нажать «Режим проверки визуала»;
- проверить бургер;
- проверить настройку визуала;
- нажать кружок Firebase;
- скопировать диагностику;
- проверить кнопку Назад на Android.
