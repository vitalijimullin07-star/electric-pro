# Pool V22.6 — Manual DB Candidate Picker

## Что добавлено

Ручной выбор кандидата из базы для строк подбора.

Теперь можно нажать на строку в блоке «Подбор из БД» и выбрать другую позицию из списка кандидатов.

## Зачем

Если автоподбор нашёл близкую, но не идеальную позицию, например:

- нужно 20x30, а найдено 25x30;
- найден не тот производитель;
- найден похожий материал;

мастер может вручную выбрать правильную позицию.

## Что сохраняется

Ручной выбор сохраняется в localStorage:

```text
ep_pool_v22_manual_db_choices
```

И применяется к строке черновика.
