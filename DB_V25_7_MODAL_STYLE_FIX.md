# DB V25.7 — Modal Style Fix

## Причина

БД V25.6 открывалась как обычный голый HTML внутри главного экрана/внизу страницы.  
Это означает, что CSS для БД не применился или был перебит.

## Исправлено

- CSS БД внедряется прямо из JS через `<style>`.
- Экран БД принудительно получает:
  - `position: fixed`;
  - `inset: 0`;
  - высокий `z-index`;
  - фон;
  - карточки;
  - нормальную мобильную сетку.
- БД остаётся закрытой на старте.
- БД открывается только по нажатию «База данных».
- Главный экран и бургер визуально не меняются.
