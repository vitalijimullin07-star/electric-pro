Electric Pro — V27.1 DB Clean Bridge

Назначение:
Первый рабочий шаг чистовой архитектуры V27. Не переписывает всю БД сразу, а выносит три проблемные зоны в понятные отдельные модули:
1) верхняя строка подписки/ИИ;
2) единый источник активной базы;
3) выбор «Материалы» / «Работа» с главного экрана в предварительную смету.

Что важно:
- Пул розеток не трогаем.
- Админку не трогаем.
- Подписки/ИИ-баланс не переписываем, только верхняя плашка получает один нормальный вывод.
- Старый редактор БД V26 пока оставлен, чтобы не потерять рабочую БД.
- Старые v26-патчи главного экрана и верхней плашки отключаются из index.html, но файлы физически остаются в assets/js как резерв.
