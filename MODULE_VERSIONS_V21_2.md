# Module Version Badges V21.2

Добавляет маленькие бейджи версий на карточки функций и строки бургер-меню.

## Где показывается

- На главном экране: в правом верхнем углу карточки.
- В бургер-меню: справа в строке.

## Зачем

Чтобы сразу видеть, какая функция реально прогрузилась.

Пример:

- Пул розеток/штроб — V21.
- Подписка — V20.
- Настройки — V20.
- Остальные модули пока могут быть V10/V11/V12/V13.

## Как обновлять версии

В файле:

```text
assets/js/module-version-badges-v21-2.js
```

есть карта:

```js
const ModuleVersions = {
  pool: "V21",
  shield: "V13",
  materials: "V20"
};
```

Когда соберём следующую функцию, меняем только её версию.
