# Electric Pro Master Clean V1

Чистая модульная сборка для GitHub Pages и Firebase. Старые патчи из большого HTML не перенесены. Логика разбита по независимым страницам.

## Структура

- `index.html` — главная, смета, быстрые переходы.
- `database.html` — моя база / база сервера, импорт, экспорт, добавление в смету.
- `shield.html` — конфигуратор щита.
- `pool.html` — пул розеток и BIM.
- `documents.html` — заготовки договора, акта, КП, чек-листа.
- `settings.html` — настройки, тема, заявки мастеров.
- `assets/js/firebase-config.js` — Firebase config в одном месте.
- `firestore.rules` — правила Firestore для публикации в Firebase.

## Запуск на GitHub Pages

1. Очистить репозиторий.
2. Загрузить все файлы из этой папки в корень репозитория.
3. В GitHub включить Pages: `Settings → Pages → Deploy from branch → main / root`.
4. В Firebase Authentication добавить домен GitHub Pages в Authorized domains.
5. В Firestore опубликовать правила из `firestore.rules`.
6. Открыть сайт. Для быстрой проверки можно нажать «Демо без входа».

## Firebase

Используются коллекции:

- `users/{uid}` — профиль мастера, роль, статус допуска.
- `server_db/{itemId}` — общая база сервера.
- `user_db/{uid}/items/{itemId}` — личная база мастера.
- `estimate_drafts/{uid}` — текущая смета мастера для просмотра админом в будущем.

Первый админ задаётся в `assets/js/firebase-config.js` через `EP_ADMIN_EMAILS`.

## Что уже есть

- Вход через Google + демо-режим.
- Разделение базы: «Моя база» и «База сервера».
- Копирование позиций с сервера в личную базу.
- Импорт текста/JSON и экспорт JSON.
- Стартовая база, собранная из рабочего файла мастеров.
- Щит: помещения, отдельные линии, тип защиты, влажные зоны 10 мА, мастер-кнопка только свет, подбор цен из активной базы.
- Пул: группы механизмов, кабель, подрозетники, штроба, бурение, работы.
- Документы: договор, акт, КП, чек-лист как печатные заготовки.
