# Electric Pro Hybrid V2

Гибридная сборка: каркас рабочего файла 842 КБ + логика базы/щита/пула из сборки 639 КБ.

Главный файл `index.html` самодостаточный: CSS и JS внутри, чтобы GitHub Pages запускался даже без assets.

Модули:

- shield.html — переход к щиту
- pool.html — переход к пулу
- documents.html — переход к документам
- settings.html — переход к настройкам

Firestore: см. `firestore.rules`.
