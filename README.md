# Plata — редактор печатных плат в браузере

Полноценный редактор плат в духе EasyEDA: библиотека корпусов с реальными размерами, шаблоны плат, трассировка на одном или двух слоях, проверка правил на лету, автотрассировка, экспорт Gerber для завода и SVG 1:1 для домашнего ЛУТ. Работает на компьютере и телефоне, ничего не нужно устанавливать; проект хранится в браузере и в файле. Облако и учётные записи — следующий этап.

Первая плата в комплекте — контроллер самодельного строительного пылесоса (ESP32, две турбины через MOC3021 и BTA41, датчики, два HLK-PM01, зона 230 В), перенесённая из первой версии Plata.

## Что умеет

**Плата и компоненты**

- Один или два слоя меди, контур любой формы, скруглённые углы, вырезы, крепёжные отверстия.
- Библиотека из ~190 корпусов: чипы 0402…2512 (R, C, L, диоды, светодиоды, предохранители), SMA/SMB/SMC, SOD, тантал, SOT-23/-223, SOIC, TSSOP, MSOP, QFP; выводные DIP, штыри и гнёзда 2,54 и 2,0 мм, JST XH/PH, винтовые клеммники, резисторы и диоды с осевыми выводами, электролиты, TO-92, TO-220, светодиоды, держатель предохранителя, варисторы, зуммер, кнопки, реле, крепёж.
- Модули на штырях: ESP32 DevKit (30 и 38 выводов), NodeMCU, D1 mini, Arduino Nano и Pro Mini, Raspberry Pi Pico, Blue Pill, HLK-PM01, ADS1115, DS3231, MAX31855, LM2596, модуль реле, OLED 0,96″, DHT22, произвольный модуль.
- У каждого корпуса пометка: размеры сверены со стандартом или типовые (проверить по даташиту). Совместимые корпуса можно менять одним щелчком (SMD ↔ выводной).
- Шаблоны: пустые платы ходовых размеров, плата под ЛУТ, еврокарта, шилд Arduino Uno с отверстиями по чертежу, Raspberry Pi HAT, плата под Pi Pico, корпус на DIN-рейку.
- Перетаскивание, поворот, перенос на другую сторону, рамка выделения, стрелки для точного сдвига, отмена и повтор.

**Цепи и трассировка**

- Цепи назначаются выводам в свойствах компонента; классы цепей задают зазор, ширину дорожки и размер переходного. Класс «Сеть 230 В» с зазором 6 мм до всего остального и область правил «Зона 230 В».
- Ручная трассировка с изгибами 45°, автоширина по классу, переходные отверстия с переходом на другой слой (V), перемычки проводом для односторонних плат, воздушные линии до ближайшего островка цепи.
- Проверка правил на лету: зазоры между цепями с учётом классов, замыкания, неразведённые цепи, край платы, минимальные ширины и отверстия, кольца, расстояние между отверстиями, запретные области и области только для своих классов, перекрытие габаритов, висящие дорожки.
- Автотрассировка методом согласования конфликтов в фоновом воркере: один слой с перемычками или два с переходными, учитывает классы, области правил и зону 230 В; можно развести всё или только недоведённые цепи.

**Экспорт**

- На завод: Gerber RS-274X с атрибутами X2 (медь, маска, шелкография, паста, контур), сверловка Excellon (PTH и NPTH), перечень элементов и файл расстановки — одним архивом.
- Дома: медь в SVG 1:1 (размеры в мм в самом файле, точки под кернение), сборочный вид, список соединений, комплект архивом.
- Проект в JSON (самодостаточный: корпуса внутри), недавние проекты в браузере, импорт проектов первой версии Plata.

## Как открыть

**Локально**

```
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/
npm run preview      # посмотреть сборку
```

**GitHub Pages.** В репозитории: Settings → Pages → Source → GitHub Actions. Рабочий процесс `.github/workflows/ci.yml` при каждом push в `main` проверяет типы, прогоняет тесты, собирает и публикует `dist/`. Пути в сборке относительные, поэтому она открывается и из подпапки, и просто с диска через любой статический сервер.

## Как пользоваться

1. **Файл → Новый проект**: выберите шаблон или задайте размер, число слоёв и правила (завод или ЛУТ).
2. **Библиотека** (вкладка справа или клавиша P): найдите корпус, «Поставить на плату», щёлкните по плате. R — поворот, Esc — закончить.
3. **Двойной щелчок по компоненту**: обозначение, номинал, замена корпуса, назначение цепей выводам (новое имя создаёт цепь).
4. **Дорожка (W)**: щелчок по площадке — начало, щелчки ставят изгибы, щелчок по площадке той же цепи заканчивает. V — переходное и смена слоя, Backspace — убрать изгиб, `/` — тип изгиба.
5. **Трассировка → Автотрассировка**: развести всё или только оставшееся.
6. **Проверка** (вкладка справа): список замечаний, щелчок ведёт к месту на плате.
7. **Файл → Экспорт**: архив Gerber для завода или SVG 1:1 для ЛУТ.

Горячие клавиши — в меню «Справка».

## Структура

```
index.html, src/app/            точка входа и раскладка
src/core/math/                  векторы, отрезки, многоугольники, фигуры (капсулы, скруглённые прямоугольники), пространственный индекс
src/core/model/                 модель проекта, слои, правила и классы цепей, размещение корпусов, геометрия в координатах платы,
                                связность и воздушные линии, проверка правил (DRC), операции редактирования
src/core/library/               библиотека корпусов (генераторы SMD, выводных, модулей), шаблоны плат
src/core/router/                автотрассировка и её воркер
src/core/io/                    Gerber/Excellon, SVG, BOM и расстановка, файл проекта, архивы, импорт старого формата
src/core/render/                штриховой шрифт и развёртка проекта в примитивы по слоям
src/core/examples/              плата пылесоса
src/editor/                     состояние редактора (zustand + immer), история, команды, обработка мыши и касаний
src/render/                     отрисовка на Canvas и проверка попадания курсора
src/ui/                         React: меню, панель инструментов, холст, панели, диалоги, стили
tests/                          vitest: библиотека, плата пылесоса, автотрассировка, экспорт
tools/e2e.mjs                   сквозной прогон интерфейса в Chromium (Playwright), запускается вручную
```

Ядро не зависит от React и DOM: работает в воркере и в Node, поэтому автотрассировка и экспорт покрыты тестами.

## Формат проекта

Все размеры в миллиметрах, ось Y вниз. Проект — один JSON: метаданные, плата (контур, слои, толщина), правила, классы цепей, цепи, копии используемых корпусов, компоненты (положение, поворот, сторона, вывод → цепь), дорожки (ломаные с шириной и слоем), переходные, перемычки, полигоны, области правил, графика. Версия формата хранится в поле `version`; старые файлы дополняются при открытии.

## Проверки

