# Pool V21

V21.1 — первый рабочий модуль пула.

- отдельный модуль `PoolV21`;
- визуал под текущий Electric Pro;
- старый Clean V3 визуал не используется;
- пул не хранит свою базу;
- пул формирует сущности и ищет позиции через активную базу;
- если позиция не найдена — показывает missing;
- добавление в смету ищет существующие методы сметы.

Следующие этапы:

- V21.2 — вернуть старую глубокую логику высот/расходки;
- V21.3 — улучшить DB Resolver и ручной выбор кандидата;
- V21.4 — нормальная связка со сметой;
- V21.5 — серверная проверка лимитов;
- V21.6 — чистая сборка пула без временных патчей.
