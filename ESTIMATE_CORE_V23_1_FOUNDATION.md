# Estimate Core V23.1 — Foundation

## Что добавлено

Создано единое ядро черновика сметы:

```text
assets/js/estimate-core-v23-1.js
```

Хранилище:

```text
localStorage: ep_estimate_draft_v23
```

## Зачем

Чтобы все функции писали результат в один центр:

- пул;
- конфигуратор щита;
- будущие функции;
- ручные добавления.

А потом уже из этого центра будут брать данные:

- смета клиенту;
- поставщику;
- детализация;
- PDF;
- бухгалтерия.

## Подключено сейчас

Первым подключён пул V22.7:

- в пул добавляется кнопка «Добавить в единый черновик сметы»;
- в бургер-меню добавляется «Черновик сметы»;
- строки пула нормализуются и сохраняются в единый черновик.

## Формат строки

```js
{
  source: "pool",
  sourceVersion: "V22.7",
  type: "work" | "material",
  name: "...",
  dbName: "...",
  qty: 1,
  unit: "шт",
  price: 100,
  total: 100,
  missingDb: false,
  warning: "",
  customerVisible: true,
  supplierVisible: false
}
```
