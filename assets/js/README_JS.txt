Папка assets/js

app-shell.js — оболочка, бургер, модалки, кнопка назад.
router.js — загрузка pages/*.html.
visual-settings.js — темы и ручные настройки.
diagnostics.js — единая диагностика с файлом/модулем/функцией.
auth.js — Google/Firebase вход и режим проверки визуала.
server-api.js — единственное место прямого общения с Firebase.
crypto-api.js — Web Crypto API.
cache-api.js — зашифрованный IndexedDB-кэш.
change-log-api.js — локальный журнал изменений.
sync-api.js — минутная синхронизация и склейка изменений.
database-api.js — поиск и работа с базой через прослойку.
estimate-api.js — смета и суммирование.
