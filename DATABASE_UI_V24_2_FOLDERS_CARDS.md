# Database UI V24.2 — Folders + Cards

## Что изменено

По пожеланию пользователя:

- работы и материалы вынесены в отдельные кнопки;
- категории раскрываются как папки;
- подкатегории кликабельные;
- позиция открывается карточкой;
- из карточки можно перейти к редактированию.

## Важно

V24.2 не ломает ядро V24.1. Это UI-слой поверх Database Core.

Позже, когда БД стабилизируется, можно собрать БД в монолит так же, как был собран пул V22.7.
