# Pool V22.5 — Safe DB Picker

## Что исправлено

Подбор из БД стал строже:

- работа ищется только среди работ;
- материал ищется только среди материалов;
- высверливание больше не должно брать подрозетник;
- подрозетник больше не должен брать высверливание;
- штробление ищет только работу по штроблению;
- монтаж распайки ищет монтаж/установку, а не саму коробку;
- если размер штробы отличается, показывается предупреждение.

## Зачем

V22.4 доказал, что подбор работает, но мог подобрать работу как материал.
V22.5 делает подбор безопаснее, чтобы цена не подтягивалась от неправильной сущности.
