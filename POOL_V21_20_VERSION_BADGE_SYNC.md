# Pool V21.20 — Version Badge Sync

## Что исправлено

Внутри пула в шапке показывалась старая версия V21.16, хотя следующие модули уже могли быть подключены.

## Причина

Старые модули пула перерисовывали шапку и возвращали свой бейдж версии.

## Что сделано

- добавлен отдельный синхронизатор версии;
- версия пула принудительно ставится как V21.20;
- обновляется шапка внутри пула;
- обновляется карточка пула на главном экране;
- синхронизация повторяется несколько раз после открытия, чтобы старые перерисовки не откатывали версию.

## Важно

V21.19 был про авторизацию, а не про пул. Поэтому для пула новая контрольная точка — V21.20.
