# DB V25 — Hard Monolith

## Причина

После V24.5 кнопка «База данных» стала открывать старую заглушку:

> Логика будет подключаться через прослойки, без прямого обращения модуля к Firebase.

Значит маршрут/меню уходили в старый экран БД, а не в новый файловый менеджер.

## Что сделано

- Создан новый отдельный монолит:
  `assets/js/database-v25-hard-monolith.js`
- Он сам рисует экран БД поверх приложения.
- Он перехватывает:
  - клики по «База данных»;
  - `DatabaseV24CleanMonolith.open`;
  - `DatabaseFileManagerV243.open`;
  - `Router.load("database")`.
- Старые заглушки БД скрываются.
- Внутри есть:
  - БД сервера;
  - БД моя;
  - БД мастеров;
  - папки/подпапки/позиции;
  - галочки;
  - удалить/переместить;
  - импорт JSON;
  - импорт из БД сервера;
  - диагностика БД.
