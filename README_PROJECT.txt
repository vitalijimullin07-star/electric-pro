Electric Pro Clean — стартовая модульная сборка V1

Главная идея:
index.html — оболочка приложения.
pages/ — HTML-вкладки, которые загружаются внутрь index.html через router.js.

В первой сборке есть:
- тонкая верхняя шапка;
- левый бургер;
- главный экран;
- настройка визуала;
- 10 тем;
- диагностика ошибок с указанием файла;
- копирование диагностики;
- Android-кнопка назад внутри приложения;
- подготовка под Firebase;
- подготовка под зашифрованный кэш;
- подготовка под ChangeLog и минутную синхронизацию;
- README-файлы.

Правило проекта:
Модули не обращаются напрямую в Firebase.
Модуль → DatabaseAPI / EstimateAPI → CacheAPI / SyncAPI → ServerAPI → Firebase.
