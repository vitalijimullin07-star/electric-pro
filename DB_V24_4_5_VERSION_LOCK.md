# DB V24.4.5 — Version Lock

## Причина

Пользователь заметил: при открытии БД сначала появляется новая версия, потом экран резко откатывается назад на старую версию V24.4.1.

Это означает, что старый слой перерисовывает шапку БД уже после нового фикса.

## Что сделано

- Добавлен лёгкий сторож только для шапки БД.
- Скрипт подключается самым последним.
- Версия БД принудительно удерживается как V24.4.5.
- Точка диагностики остаётся в шапке БД.
- Плавающая точка справа скрывается.

## Важно

Это временная защитная мера. После стабилизации БД нужно собрать чистый монолит без поздних перерисовок.
