# V21.6 Pool Reset/Delete/Sound Fix

Исправляет ошибки V21.5:

- если механизмов 0, посты не остаются на 6;
- при пустой рамке посты автоматически возвращаются на 1;
- после добавления рамки значения сбрасываются корректно;
- кнопка «Очистить» работает;
- крестик удаления строки работает;
- добавлен звук на клики, успех и ошибку;
- добавлен нижний отступ, чтобы кнопки не прятались под Android-панелью.

## Важно

Это временный фикс поверх V21.1-V21.5.
После полной проверки пула нужно будет собрать пул чисто без этих патчей.
