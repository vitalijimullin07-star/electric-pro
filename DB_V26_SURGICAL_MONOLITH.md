# DB V26.0 — Surgical Monolith

## Главное правило

Не трогаем главный экран и не перерисовываем бургер-панель.

## Что делает

- Подключает один файл: `assets/js/database-v26-surgical-monolith.js`.
- БД не открывается автоматически.
- БД открывается только по нажатию строки «База данных» в существующем бургере.
- БД открывается fullscreen-окном поверх приложения.
- У строки «База данных» оставляет один бейдж версии: `V26.0`.
- Прошлые неудачные V25/DB-патчи удаляются только из подключений `index.html`.

## Внутри БД

- БД сервера / БД моя / БД мастеров для админа.
- Редактор БД свернут по умолчанию.
- Кнопки Работа / Материал.
- Папки / подпапки / карточки позиций.
- Галочки для массовых действий.
- Добавить / удалить / переместить.
- Импорт из БД сервера.
- Экспорт JSON.
- Импорт JSON / текст.
- Диагностика по красной точке.
