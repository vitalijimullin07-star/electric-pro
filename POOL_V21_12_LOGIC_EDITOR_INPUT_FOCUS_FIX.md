# Pool V21.12 — Logic Editor Input Focus Fix

## Что исправлено

- Клик по полям редактора логики больше не должен сворачивать редактор.
- Touch/click/pointer события внутри редактора останавливаются и не долетают до кнопки сворачивания.
- При фокусе в любом поле редактор принудительно остаётся открытым.
- Состояние открытого редактора сохраняется.
- Версия пула обновлена до V21.12.

## Почему это было

Старые временные обработчики клика из предыдущих слоёв могли ловить нажатия внутри редактора как команду свернуть блок.
V21.12 ставит защиту именно на тело редактора и input-поля.
