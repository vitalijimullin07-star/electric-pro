# Database V24.3.3 — Import + Autosave

## Исправлено / добавлено

1. Подсветка активного выбора:
   - БД сервера / БД моя / БД мастеров;
   - Работа / Материал.

2. Импорт из БД сервера вынесен отдельной кнопкой:
   - по умолчанию свернут;
   - открывает отдельное окно;
   - внутри папки, подпапки и позиции;
   - можно выделить папку, подпапку, позицию или всё сразу.

3. Добавление в Мою БД:
   - с ценой;
   - без цены.

4. Автосохранение:
   - после изменения базы сохраняет localStorage;
   - показывает индикатор сохранения;
   - если доступен Firebase compat, пытается сохранить:
     - my → ep_user_database_v24/{uid}
     - server → ep_database_v24/server
   - если сервер недоступен, показывает локальное сохранение.

5. Чистка дублей «База данных» в меню.
