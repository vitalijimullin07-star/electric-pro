# Зашифрованные заметки

`krylchatka-drel.tgz.enc` — крыльчатка охлаждения дрели алмазного сверления (просьба друга): исходная модель,
скрипты CadQuery всех версий (v3 — текущая), заметки `ZAMETKI.md` и что дальше, ролик потока. Пароль хранится у автора, в репозитории его нет.

Распаковать:

    openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in notes/krylchatka-drel.tgz.enc -pass pass:ПАРОЛЬ | tar -xz -C папка
