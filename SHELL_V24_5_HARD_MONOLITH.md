# Shell V24.5 — Hard Monolith

## Что сделано

Собран жёсткий монолит главной оболочки и бургер-панели:

- бургер-меню перерисовывается одним стабильным модулем;
- версии больше не мерцают;
- строки меню выровнены по сетке:
  - иконка;
  - название;
  - версия;
- «База данных» в меню одна;
- версия БД удерживается как V24.5;
- точка диагностики БД остаётся в шапке БД;
- старые плавающие точки диагностики справа скрыты;
- скрипт подключается самым последним.

## Почему это сделано

Старые слои меню и бейджей версий перерисовывали бургер-панель после открытия. Из-за этого версия сначала становилась новой, потом откатывалась назад.

V24.5 ставит единый жёсткий рендер меню и лёгкий сторож только для меню/шапки БД.
