# Pool V21.14 — Prompt Edit Fields

## Что сделано

В пуле больше не используются обычные input-поля для критичных настроек:

- высота потолка;
- своя высота;
- поля редактора логики.

Теперь эти значения меняются нажатием на плашку.
После нажатия открывается системное окно ввода `prompt`.

## Почему

На текущей сборке input-поля не получают фокус: вероятно, есть глобальный перехват событий/слой интерфейса.
Чтобы не тратить время на невидимый конфликт, V21.14 обходит проблему полностью.

## Важно

Это рабочий обходной вариант. Позже, когда пул будем чистить без патчей, можно будет вернуть нормальные input-поля уже в чистой архитектуре.
