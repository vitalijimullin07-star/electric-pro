# Pool V22.5.1 — Force Safe Picker

## Что исправлено

V22.4 продолжал перехватывать кнопку «Подобрать из БД», поэтому в интерфейсе оставался старый результат:

- показывалось V22.4;
- источник был `ep_pool_v22_db_pick_result`;
- высверливание могло подбирать подрозетник.

V22.5.1:

- убирает подключение V22.4 из index.html;
- перехватывает кнопку подбора;
- запускает только безопасный подбор V22.5.1;
- очищает старый результат;
- запрещает подбирать материал-подрозетник для работы высверливания.
