Electric Pro V27.2 — main picker route guard

Цель:
- исправить ситуацию, когда на главном экране кнопки «Материалы» и «Работа» открывали всю БД;
- оставить чистый V27 picker для выбора позиции из активной базы;
- не трогать пул, щит, админку, подписки и Firebase-данные.

Причина бага:
старый слой БД V26 ловил слово "database" внутри inline onclick="window.EPDatabasePickerV27..." и открывал полный экран БД раньше нового обработчика.

Что сделано:
- у карточек «Материалы» и «Работа» убран inline onclick;
- выбор идёт через data-ep27-pick / data-ep27-db-picker;
- старые V26 route guards больше не перехватывают V27 picker tiles;
- V26.15/V26.16 главные патчи отключаются из index.html;
- V27 top status / database gateway / picker остаются подключены.

Проверка:
1. Открыть ?fresh=272.
2. Главный экран → Материалы: должен открыться список материалов, а не вся БД.
3. Главный экран → Работа: должен открыться список работ, а не вся БД.
4. Вверху picker должна быть правильная активная база.
5. Плюс/минус должен менять предварительную смету.
